Fasthand OCR

Extract text from images in real time. Built by Fasthand Studio.

Workers AI Llama 3.2 Vision TypeScript Edge Runtime API Key Auth

POST /

Send a base64-encoded image and get back every word the vision model can read. Accepts JPEG, PNG, and WebP.

  • Requires a valid API key in the X-API-Key header
  • HTTPS only, CORS enabled for all origins
  • Returns extracted text and per-word confidence scores

Authentication

Every request must include your API key. The key is validated with a timing-safe comparison and never exposed in responses.

Headers
X-API-Key string Required. The secret key issued for your account.
Content-Type string Must be application/json
Missing or invalid keys return 401. Keep the key out of client-side code and browser bundles.

Request

JSON body with a single field.

Body
image string Base64-encoded image. Data-URL prefix data:image/...;base64, is stripped automatically. 
{
  "image": "iVBORw0KGgoAAAANSUhEUg..."
}

Response

All responses are JSON with CORS headers.

200 OK
{
  "success": true,
  "text": "Organic Whole Milk 2%",
  "words": [
    { "text": "Organic", "confidence": 0.92 },
    { "text": "Whole", "confidence": 0.88 },
    { "text": "Milk", "confidence": 0.95 },
    { "text": "2%", "confidence": 0.87 }
  ]
}
Response fields
success boolean true when OCR completes without error.
text string Full extracted text, cleaned of LLM preamble artifacts.
words array Individual words with a confidence score between 0 and 1.
words[].text string A single word from the extracted text.
words[].confidence number Estimated confidence. Defaults to 0.85 since Workers AI does not provide per-word scores.

Error responses

StatusCauseBody
401 Missing or invalid X-API-Key {"success":false,"error":"Unauthorized: missing or invalid X-API-Key header"}
400 Missing image field, invalid base64 {"success":false,"error":"No image provided"}
413 Body over 8 MB or image over 6 MB {"success":false,"error":"Request body too large"}
405 Non-POST request Method not allowed
500 Model or decode failure {"success":false,"error":"..."}

Try it

cURL. Replace the image value with a valid base64-encoded PNG or JPEG.

curl -X POST https://fasthand-ocr-worker.fasthand.workers.dev/ \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"image": "iVBOR..."}'
Processing pipeline
1 Verify API key (timing-safe) and enforce size limits.
2 Validate base64, strip data-URL prefix, decode to byte buffer.
3 Send image + OCR prompt to Llama 3.2 Vision via Workers AI.
4 Parse model output, strip preamble and markdown fences.
5 Split cleaned text into words with confidence scores.
Response times depend on image complexity. Typical latency is 1-8 seconds.

Integration

This worker is designed to be called from a backend service. The recommended flow:

1 Capture a frame from the device camera.
2 Base64-encode the image data.
3 POST to this endpoint with {"image": "..."}.
4 Read the text field from the response.
